## 🏗️ What I Built
A lightning-fast, sleek slate-themed document parser built using FastAPI, LangChain, and Groq open-weights framework.

## 🛠️ My Tech Stack & Open-Source Core
AI Core Framework: Llama 3 (llama3-70b-8192) running via the hyper-fast Groq Cloud API.
Orchestration Layer: FastAPI + LangChain Core prompt modeling pipelines.
Frontend Dashboard: Custom deep-slate responsive user interface built using Tailwind CSS.
Deployment Platform: Hosted securely as a cloud application using Render Web Services.
